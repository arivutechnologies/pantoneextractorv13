# Pantone Extractor design system

Product: private PDF color extraction workspace for designers and production teams. Key flows: secure login, upload one PDF, show processing state, provide separate PNG/PDF/CSV downloads with a 30-minute expiry.

Visual direction: high-contrast ink-and-paper utility interface. Near-black #11100F canvas, warm paper #F4F0E8 surfaces, orange #FF6B2C action accent, muted stone #A59E93. Use Arial/Helvetica system sans, tight oversized headlines, thin dark borders, compact metadata, direct labels, and restrained motion. No gradients, no decorative imagery, no extra colors.

The interface must feel precise, calm, and production-oriented. Auth messaging must be clear; never expose secrets or uploaded file contents. Use responsive single-column layout on mobile and generous editorial spacing on desktop.
